# ShutterMats Frontend

Frontend for ShutterMats, built with React and Vite.  
This interface supports two roles: Athlete and Admin.

## Tech Stack
- React 18+
- Vite
- Sass (SCSS)
- React Router
- Fetch/Axios for API calls

## Getting Started

### 1. Install dependencies
```
npm install
```

### 2. Run the development server
```
npm run dev
```

### 3. Project Structure (initial)
```
src/
components/
pages/
styles/
base/
components/
pages/
variables.scss
mixins.scss

```

More pages and components will be added as the UI design progresses.
